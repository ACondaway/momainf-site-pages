Pipeline流程

One continuous path from intent to evaluation从意图到评测的一条连续路径

MoMaInf keeps each handoff explicit: a language model proposes structure, tools resolve the world, simulators produce data, and benchmark adapters turn episodes into comparable evidence.MoMaInf 让每一次交接都可见：语言模型提出结构，工具解析世界，仿真器生成数据，benchmark adapter 将 episode 转化为可比较的证据。

01

Semantic layer语义层

A scene is a graph of named entities and relations, not a pile of mesh paths. This is where human language, asset search and task hints meet.场景是带名称的实体与关系图，而不是一堆网格路径；人类语言、资产检索和任务提示在这里汇合。

02

Execution layer执行层

A skill consumes a typed request and returns a traceable result. The embodiment adapter owns kinematics and controllers; the task language stays portable.技能消费类型化 request 并返回可追踪 result；本体适配器负责运动学和控制器，任务语言保持可移植。

03

Evidence layer证据层

Every generated world and episode keeps provenance, diagnostics and failure categories so data can be audited before it enters a benchmark.每个生成世界和 episode 都保留来源、诊断与失败类别，数据进入 benchmark 前可以被审计。

Team团队

One team, one main branch一个团队，一条 main 分支

Since October 2026 the team develops directly on main: small commits that carry their tests and evidence, reviewed after they are pushed. The repository is private; team members can ask the project owner for access.从 2026 年 10 月起，团队直接在 main 上开发：小而清晰的提交，附带测试与证据，推送后由其他成员评审。代码仓库是私有的，团队成员可向项目负责人申请访问权限。
